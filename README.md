# Stark Holographic Engineering Workstation

An interactive, Stark Industries-inspired 3D holographic engineering workstation featuring gesture-controlled UI, real-time 3D component manipulation, and computer-vision-powered AR face/visor tracking.

---

## 🚀 Features
- **Hand-Tracked Gestures:** Control the interface and manipulate 3D elements using hand gestures (pinching, palm-spread exploded views, two-finger zooming).
- **3D Component Manipulation:** Powered by the Ursina Engine for rendering high-tech holographic engineering components.
- **AR Face & Visor Overlay:** Real-time face tracking with vectorized alpha blending for futuristic holographic head-up displays (HUDs).
- **Modern MediaPipe Tasks API:** Built using the latest MediaPipe Vision APIs for robust, high-performance hand and face detection.

---

## 🛠️ Tech Stack
* **Python**
* **Ursina Engine** (3D Rendering)
* **MediaPipe** (Vision Tasks / Landmark Detection)
* **OpenCV & NumPy** (Image processing & vectorized alpha blending)
* **Tkinter** (File dialogs)
